## 🎯 جریان کامل مثال اسکن

```
┌─────────────────────────────────────────────────────────────┐
│    مثال: nmap -sS -sV -sC -O -A -T4 target                 │
└─────────────────────────────────────────────────────────────┘

1. مشخصات هدف
   └─> target (192.168.1.1 یا domain.com)

2. تنظیم زمان‌بندی
   └─> -T4 (الگوی زمان‌بندی تهاجمی)

3. کشف میزبان (ضمنی)
   └─> پروب‌های ping استاندارد ICMP/TCP

4. تکنیک اسکن
   └─> -sS (اسکن TCP SYN)

5. اسکن پورت
   └─> پورت‌های برتر پیش‌فرض 1000

6. تشخیص سرویس
   └─> -sV (تشخیص نسخه در پورت‌های باز)

7. اسکن اسکریپت
   └─> -sC (اسکریپت‌های NSE پیش‌فرض)

8. تشخیص سیستم عامل
   └─> -O (تشخیص OS)
```

```
┌─────────────────────────────────────────────────────────────┐
│                    وضعیت‌های پورت                            │
└─────────────────────────────────────────────────────────────┘

         ┌─────────────────┐
         │   باز           │  ← پورت در حال پذیرش اتصال
         │   (open)        │
         └─────────────────┘
                  │
                  ├─────────────────┐
                  │                 │
         ┌─────────────────┐       │
         │   فیلتر شده     │       │
         │   (filtered)    │  ← فایروال/IDS در حال مسدود کردن
         └─────────────────┘       │
                  │                 │
                  │         ┌─────────────────┐
                  │         │   بسته          │
                  │         │   (closed)      │  ← پورت در حال گوش دادن نیست
                  │         └─────────────────┘
                  │
         ┌─────────────────┐
         │   باز|فیلتر شده │  ← نامطمئن (UDP, FIN و غیره)
         │   (open|filtered)│
         └─────────────────┘
                  │
         ┌─────────────────┐
         │   بسته|فیلتر شده│  ← نامطمئن (نادر)

         └─────────────────┘

──────────────────

نامطمئن:    استفاده با اسکن‌هایی که نمی‌توانند تمایز قائل شوند
```
